System Integration Flow

The Robot Shelver operates through a sophisticated ReAct loop: The AutonomousBookSearchAgent (controller.py) receives visual input through the Perception system (perception/perception.py), reasons about the next action using an LLM, then executes camera movements (camera/camera_controller.py) to gather more information. When books are detected, the system can plan navigation (navigation/) and manipulation (manipulation/pick_place_demo.py) sequences with the enhanced joint unlocking system. All operations occur within a physics-accurate simulation (environment.py) that manages joint motors with coordinated flag states, collision detection, and realistic dynamics. The enhanced manipulation system uses multiple methods to ensure joints remain unlocked and have sufficient power (15000+ gain, 150000+ impulse) to overcome physical constraints. The main loop (main.py) coordinates the entire system while maintaining visual feedback and recording capabilities.
