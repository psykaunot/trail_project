Key Capabilities & Interactions

Manual Control System

Control the robot directly through keyboard inputs with immediate feedback.

  • Drive robot with arrow keys (differential wheel control)
  • Multi-joint arm positioning with individual control
  • Gripper open/close with physics-based interaction
  • Camera pan/tilt with stability compensation

Autonomous Operation System

LLM-powered decision making for complex missions with minimal human input.

  • Book-finding missions using vision and navigation
  • LLM-guided exploration and decision making
  • Camera-guided search patterns with systematic scanning
  • Multi-stage task planning and execution

Visual Intelligence System

Advanced visual perception using vision-language models for scene understanding.

  • Real-time object detection with accurate bounding boxes
  • Scene description and analysis using vision-language models
  • 2D to 3D coordinate mapping for spatial awareness
  • Book detection with position estimation for manipulation

Navigation & Manipulation System

Physics-based movement and object interaction with collision avoidance.

  • NavMesh pathfinding with obstacle avoidance
  • Physics-based wheel control for smooth movement
  • Camera-guided precision grasping sequences
  • Multi-stage pick-and-place operations with books

System Integration

The Robot Shelver demonstrates advanced integration between perception, planning, and action systems. The main control flow begins with visual perception (perception/perception.py) analyzing the environment, followed by intelligent decision-making (controller.py) to determine appropriate actions. These decisions are executed through navigation (navigation/navmesh_navigator.py) and manipulation (manipulation/pick_place_demo.py) systems, all operating within a physics-accurate simulation environment (environment.py). The project showcases how language models can be integrated with robotics to create sophisticated autonomous behaviors.
